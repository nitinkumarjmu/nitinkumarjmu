## projects

**♟ Chess Platform** &nbsp;·&nbsp; `React 18` `TypeScript` `Spring Boot 3` `PostgreSQL 16` `WebSocket (STOMP)` `JWT` `AWS`

Production-grade chess platform with real-time gameplay, ELO rating system, matchmaking queue, leaderboard, friends system, and PGN history on AWS S3. Server-authoritative move validation, JWT auth, and CI/CD on ECS Fargate.

---

**💬 FuncChat Pro** &nbsp;·&nbsp; `Java` `Netty WebSocket` `Firebase` `AWS S3` `Docker`

Self-hosted real-time chat app — a drop-in alternative to subscription tools like Slack. Three-tier client-server with a functional dispatch table, Java 8+ FP constructs, Firebase Realtime DB, and Docker on AWS EC2. 13 WebSocket actions · 40+ unit tests.

---

**🛍 Product Recommendation Engine** &nbsp;·&nbsp; `React` `Spring Boot` `PostgreSQL 15` `Redis 7`

E-commerce recommendation system using KNN for nearest-neighbour item similarity. Solves cold-start and relevance problems with Redis caching for real-time suggestions, built on SOLID/OOP REST API architecture.
